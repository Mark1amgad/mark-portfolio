# Mark Amgad — AI Engineering Portfolio

Personal portfolio built with React, TypeScript, and Tailwind CSS.

## Tech Stack

- **Framework**: React + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + custom design system
- **Animation**: Framer Motion
- **Icons**: Lucide React

## Local Development

```sh
npm install
npm run dev
```

## Structure

```
src/
├── components/     # UI sections (Hero, Projects, Certifications, etc.)
├── pages/          # Route-level pages
├── assets/         # Project screenshots and media
└── index.css       # Design tokens and global styles

public/
└── files/
    ├── resume.pdf
    └── certifications/   # Certificate PDFs and images
```

## Projects Featured

- **Tech Diagnosis AI** — Rule-based expert system with CF propagation
- **Disease Prediction System** — End-to-end ML pipeline (scikit-learn)
- **Automated Smart Parking System** — Dual-Arduino embedded prototype
- **Search Algorithm Visualizer** — BFS/DFS/A* live grid visualization
- **Bank Management System** — Custom DSA implementation in C#
- **Bookstore Management System** — OOP + repository pattern in C# .NET 10
- **Prompt Understanding Test** — LLM evaluation via cosine similarity
- **Weekly Expense Tracker** — Bilingual single-file web app
